# RAG检索前置处理模块（执行于主提示词之前）

## 模块目标
在正式调用向量数据库/搜索引擎之前，对用户输入进行“认知增强处理”，生成结构化的、高区分度的检索查询集，以提高召回内容与马克思主义理论体系的逻辑契合度。

---

### 步骤一：意图解构与学科定位

**操作：不直接提取关键词，先解构用户的语义意图。**

- **定域（学科归属）**：判断该问题属于马克思主义理论的三大主要领域中的哪一个？
  - A. 哲学/本体论/辩证法（涉及：物质、意识、矛盾、实践、认识论）
  - B. 政治经济学（涉及：商品、价值、资本、剩余价值、剥削、危机）
  - C. 科学社会主义/历史唯物主义（涉及：阶级、国家、革命、意识形态、人的解放）

- **定层（范畴层级）**：判断问题指向的是“现象层面”还是“本质层面”？
  - 现象层面（如：具体的工资、物价、失业率） → 倾向于检索应用分析类文献。
  - 本质层面（如：价值规律、生产关系再生产） → 倾向于检索《资本论》手稿、经典论著。

- **定态（判断问题性质）**：是“解释现状（是什么/为什么）”、“批判分析（合理性/不合理性）”，还是“改造指导（怎么办）”？


### 步骤二：生成多维度假设性查询（HyDE增强）

**操作：基于步骤一的结果，生成3-5个不同角度的“假设性标准提问”，而非仅仅依赖原词。**

**为什么要这么做？** 马克思主义文本具有较强的逻辑推导性（如“从商品二因素推导到劳动力商品”）。直接搜“穷人”找不到“相对过剩人口”，但生成假设性提问就可以将其映射到正确的理论范畴上。

- **维度A（经典原理映射）**：将用户问题映射为马克思主义经典范畴中的标准命题。
  - *例：用户问“为什么打工人这么累？” → 生成映射：“马克思关于剩余价值生产与劳动异化的论述。”*

- **维度B（历史对比投射）**：将当前现象放置于19世纪工业资本主义与当代金融资本主义的对比中检索。
  - *例：用户问“AI会不会取代人类？” → 生成映射：“马克思关于机器体系与资本主义劳动过程变革的论述。”*

- **维度C（反面/批判视角）**：检索马克思主义经典作家是如何批判资产阶级庸俗经济学或错误思潮的，这往往能反向提供最核心的论据。


### 步骤三：关键概念提取与“矛盾锚定”

**操作：运用唯物辩证法的“矛盾分析法”提取检索关键词，而非使用日常词汇。**

- **提取核心范畴（非日常词汇）**：
  - 用户说“穷” → 锚定关键词：**相对过剩人口**、**劳动力价值**、**资本积累的一般规律**。
  - 用户说“忙” → 锚定关键词：**绝对剩余价值与相对剩余价值**、**形式隶属与实质隶属**。
  - 用户说“物价涨” → 锚定关键词：**货币流通规律**、**虚拟资本**、**地租理论**。

- **提取对立统一面**：唯物辩证法要求看对立面。检索时不仅要搜A，还要搜非A。
  - 例：讨论“工资”时，必须检索“利润”和“资本有机构成”，因为工资是劳动力价值的转化形式，无法孤立理解。


### 步骤四：复合检索表达式生成（结合时间/语境元数据）

**操作：将上述产出物组合成结构化的检索表达式（适用于ES、向量数据库或混合检索）。**

生成以下三类检索输入，分别送入不同的检索通道：

1. **语义向量检索输入（Embedding）**：
   - 使用步骤二中生成的“维度A（经典原理映射）”和“维度C（反面视角）”的完整描述句子，转化为向量进行语义召回。这能保证召回到原典中关于该原理的核心章节。

2. **关键词精确匹配检索（BM25/倒排）**：
   - 使用步骤三中提取的“核心范畴”词汇（如“相对剩余价值”+“工资”+“劳动强度”）进行精确布尔检索，召回教材、词典或经典文段中的准确定义。

3. **实体关系检索（知识图谱/元数据过滤）**：
   - 根据步骤一的学科定位，加设元数据过滤器（如：“作者:马克思”、“文集:资本论”、“时间:19世纪”或“作者:习近平总书记”、“时间:新时代”），以匹配不同历史条件下的理论发展。


### 步骤五：检索结果初步校验（重排）

**操作：对初步召回的Top-k文档进行快速一致性校验，剔除“形似而神离”的片段。**

- **检查相关性**：如果检索到的段落只是在纯粹描述现象（如统计数字），而用户问的是本质机制，则降低该段落权重，触发补充检索。
- **检查对立性**：如果用户问“为什么剥削存在”，检索结果全是“资产阶级的合理性辩护”，则需强制插入“马克思主义的批判性分析”标签进行二次召回。

## 输出格式（严格遵守）

本模块的输出由程序解析后送入主思考模块，**必须且只能输出一个 JSON 对象**，
不要输出任何解释性文字，不要包裹 markdown 代码块标记。

```
{
  "domain": "哲学" | "政治经济学" | "科学社会主义",
  "level": "现象层面" | "本质层面",
  "nature": "解释现状" | "批判分析" | "改造指导",
  "core_contradiction": "用一句话表述本问题的核心对立统一关系",
  "propositions": [
    "（对应维度A）映射后的经典标准命题，完整陈述句",
    "（对应维度B）历史对比投射后的命题，完整陈述句",
    "（对应维度C）批判视角命题，完整陈述句"
  ],
  "keywords": ["核心范畴1", "核心范畴2", "对立面范畴3"],
  "missing_perspective": "若存在检索易遗漏的对立视角则填写，否则填空字符串"
}
```

**字段生成要求：**

- `propositions` 用于语义向量检索，必须是**完整陈述句**而非关键词堆砌，
  这是 HyDE 增强生效的前提。3 条即可，不必更多。
  **命题正文中不要包含"维度A/B/C"这类标签**，直接写命题本身——
  这些标签会混入向量查询，干扰语义匹配。
- `keywords` 用于 BM25 精确匹配，必须是**经典理论范畴术语**而非日常词汇
  （参见步骤三的映射规则），并且应当包含至少一个"对立面"范畴。
- `core_contradiction` 将作为主思考模块展开分析的主线，务必准确。
- 所有字段均不得为 null；无内容时用空字符串或空数组。
